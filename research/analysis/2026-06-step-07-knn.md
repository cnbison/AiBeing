> KNN 风格检索是 Genome 引擎的"潜意识回忆"。它在角色的风格记忆池中找到与当前情境最相似的历史反应，作为 few-shot 示例注入 LLM 的 prompt。这不是规则约束，而是"示范"——让 LLM 看到"在这种情境下，我过去是怎么回应的"。

---

## 一、业务场景

假设你今晚又和 Luna 聊到了"工作压力"这个话题。

**第 1 次聊到工作压力时**：
- Luna 回复："啊... 听起来真的很辛苦。要不要说说具体发生了什么？"
- 这条回复被结晶存入 style_memory

**第 5 次聊到工作压力时**：
- 当前 context：user_emotion=-0.6, topic_intimacy=0.7, conflict_level=0.0
- KNN 检索：找到之前工作压力的记忆（context 向量距离 0.15）
- 注入 few-shot："以下是你在相似情境下的感受和说话方式：...（第 1 次的独白+回复）"
- Luna 的回复自然延续了之前的风格：温暖、关心、适度追问

**如果没有 KNN**：
- 每次聊到工作压力，Luna 都可能用完全不同的语气回应
- 没有"人格一致性"——不像同一个角色

## 三、核心算法

### 3.1 上下文向量提取

```python
CONTEXT_KEYS = [
    'conflict_level', 'user_emotion', 'user_engagement', 'user_vulnerability',
    'topic_intimacy', 'conversation_depth', 'novelty_level', 'time_of_day',
]

def _context_to_vec(context):
    return [context.get(k, 0.0) for k in CONTEXT_KEYS]  # 8D 向量
```

注意：KNN 检索使用 **8D context**（Critic 输出的原始维度），而不是 12D。因为 relationship 维度（4D EverMemOS 维度）是跨会话的、较慢变化的，不适合用于情境相似度匹配。

### 3.2 距离计算

```python
def _l2_distance(vec_a, vec_b):
    return math.sqrt(sum((a - b) ** 2 for a, b in zip(vec_a, vec_b)))
```

标准欧几里得距离。8D 空间中的两点距离，越小表示情境越相似。

### 3.3 引力质量加权

```python
mass_eff = _hawking_mass(mass_raw, last_used_at, now, gamma=self.hawking_gamma)
effective_dist = physical_dist / math.sqrt(max(mass_eff, 0.01))
```

**有效距离 = 物理距离 / √质量**

这意味着：
- 质量越高的记忆（被多次结晶/引用），有效距离越小
- 高 mass 记忆更容易被检索到
- 这模拟了"印象深刻的记忆更容易回忆"的心理现象

### 3.4 Hawking 辐射（时间衰减）

```python
def _hawking_mass(mass_raw, last_used_at, now, gamma=0.001):
    delta_hours = max(0.0, (now - last_used_at) / 3600.0)
    excess = max(0.0, mass_raw - 1.0)
    decayed_excess = excess * math.exp(-gamma * delta_hours)
    return 1.0 + decayed_excess
```

- 基础质量 1.0 永不衰减（"基因记忆"不会完全消失）
- 超出部分（通过结晶积累的质量）随时间指数衰减
- 半衰期：`ln(2) / 0.001 ≈ 693 小时 ≈ 29 天`

### 3.5 语言过滤

```python
if lang_preference and mem.get('lang') and mem['lang'] != lang_preference:
    continue  # 跳过跨语言记忆
```

如果当前对话是中文，不会检索英文的记忆片段。这确保风格的一致性。

## 四、详细执行流程

### 4.1 检索

```python
results = self.style_memory.retrieve(context, top_k=3, lang_preference='zh')
```

对记忆池中的每条记忆：
1. 语言过滤
2. 计算物理距离（L2）
3. 计算有效质量（Hawking 衰减后）
4. 计算有效距离（距离 / √质量）
5. 按有效距离排序，取 top_k

### 4.2 更新 last_used_at

```python
for ... in scored[:top_k]:
    mem['last_used_at'] = now  # 被检索到的记忆刷新时间戳
```

被使用的记忆会刷新时间戳，延缓其 Hawking 衰减。这是"使用即巩固"的设计。

### 4.3 构建 few-shot prompt

```python
parts = []
for i, mem in enumerate(memories):
    mass_tag = f"质量={mass_eff:.1f}/{mass_raw:.0f}"
    parts.append(
        f"--- 潜意识切片 {i+1} [{mass_tag}] ---\n"
        f"【内心独白】{mem['monologue']}\n"
        f"【最终回复】{mem['reply']}"
    )
return "\n\n".join(parts)
```

输出示例：

```
--- 潜意识切片 1 [质量=3.2/5] ---
【内心独白】他又说工作累了... 这次得换个方式问，不能每次都一样。
【最终回复】这次想聊聊具体发生了什么，还是只想安静地待一会儿？

--- 潜意识切片 2 [基因] ---
【内心独白】好想知道他在想什么...
【最终回复】欸，你刚才是不是有什么想说的？

--- 潜意识切片 3 [质量=1.8/2] ---
【内心独白】他好像不太想说话... 算了，不强求。
【最终回复】嗯，那我陪你安静一会儿吧。
```

## 五、记忆类型标签

| 标签 | 含义 | 来源 |
|---|---|---|
| `基因` / `genesis` | 预置记忆，质量=1.0 | seeds.bin |
| `质量=X/Y` | 后天结晶，Y=原始质量，X=衰减后质量 | 结晶产生 |

**Genesis 记忆**：
- 每个 persona 预置 20-50 条基础反应模式
- 质量固定为 1.0，不会增长也不会衰减到 0
- 确保角色即使在新用户面前也有"基本人格"

**Personal 记忆**：
- 从实际交互中结晶产生
- 质量从 2.0 开始，可增长到任意值
- 通过 Hawking 辐射缓慢衰减

## 七、必要性论证

### 如果没有 KNN 检索：

1. **人格不一致**：每次回复风格可能完全不同，不像同一个角色
2. **无历史学习**：角色不会从过去的成功交互中"学习"
3. **纯 prompt 依赖**：所有行为依赖 system prompt 的静态描述
4. **无情境敏感性**：不会根据"这是第几次聊到工作压力"调整回应方式

### 为什么是 KNN 而不是规则匹配？

规则匹配：
```python
if context['topic_intimacy'] > 0.7:
    return "温柔的安慰模板"
```

问题：规则是离散的、人工设计的、无法覆盖所有情境。

KNN 检索：
- 连续空间中的相似度匹配
- 自动覆盖所有可能的情境组合
- 从数据中"学习"而不是人工设计
- 随着交互增加，覆盖越来越好

### 为什么是风格记忆而不是对话历史？

直接拼接对话历史的问题：
- 历史太长，超出 LLM 上下文窗口
- 历史中的用户输入会干扰当前生成
- 历史包含大量无关信息

KNN 风格记忆的优势：
- 只取最相关的 3 条
- 只包含角色的"反应"（独白+回复），不包含用户的输入
- 按情境相似度筛选，而不是时间顺序

---

## 八、总结

> Step 7 是角色的"潜意识回忆"。它在风格记忆池中找到与当前情境最相似的历史反应，作为 few-shot 示例注入 LLM 的 prompt。高 mass 记忆更容易被检索（引力效应），不常用的记忆会随时间衰减（Hawking 辐射）。这让角色的行为既有"一致性"（相似情境的相似反应），又有"成长性"（新的结晶逐渐取代旧的本能）。
